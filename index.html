🧩 Asosiy Formulalar

01-02 Mavzu
  • Ma'lumot = Axborot + Shakl
  • MT Modeli: S = { D, R }, R = (Tartib, Amallar)
  • Dastur = Algoritm + Ma'lumotlar
  • Ishorasiz int: 0 .. 2N - 1
  • Ishorali int: -2N-1 .. 2N-1 - 1
  • Haqiqiy son: x = ±M · q±P
  • CRUD: Create, Read, Update, Delete

💾 Xotira va C++ Turlari

02-03 Mavzu
  • Xotira qatlamlari: Heap (dinamik) → Stack (lokal/rekursiya) → Global/Static → Program Code
  • Baytlar: char=1, bool=1, int=2/4, float=4, double=8, pointer=4/8
  • Dinamik massiv: int *a = new int[n]; → delete [] a;
  • STL: Konteynerlar + Algoritmlar + Iteratorlar (5 tur)
  • clear(): array dan tashqari barcha STL konteynerlarda bor

🔎 Qidiruv Murakkabliklari

05-Mavzu
  • Linear Search: O(n) — tartib shart emas
  • Jump Search: O(√n) — tartiblangan massiv, qadam = ⌊√n⌋
  • Binary Search: O(log n) — faqat tartiblangan massiv!
  • Hash Search: O(1) o'rtacha — Xesh jadval / Python dict
  • Adjacency Matrix: Qirra tekshirish O(1), Xotira O(V²)

⚡ Saralash & Big-O Zinapoyasi

06-08 Mavzu
  • Best → Worst: O(1) → O(log n) → O(n) → O(n log n) → O(n²) → O(2ⁿ) → O(n!)
  • Stable O(n²): Bubble Sort, Insertion Sort
  • Unstable O(n²): Selection Sort, Pancake Sort
  • O(n log n): Merge Sort (Space O(n)), Heap Sort (Space O(1)), Quick Sort (Worst O(n²), Space O(log n))
  • Non-Comparison: Counting Sort, Radix Sort
